### X/Y 方向结论（重要，已被用户纠正过一次）
**`X_fa2 = Y_gen`，`Y_fa2 = X_gen`，导出必须转置。**
- 生成器写 INI：`value = X_gen + 1000*Y_gen`（X 在**低**位）。
- FA2 读 INI：`x = value / 1000`（X 在**高**位），`[Terrain]` 与 `[Waypoints]` 一致。
- 两边都没有 bug，只是同名不同义。
- 坑：生成器 `MapGenMapFile.cpp:1078` 那条"树进水"注记**不能**当判据——`[Terrain]` 键与 `[IsoMapPack5]` 出自同一个 `CellStruct`，会一起翻转，错误互相抵消。
- 转置收口在 `Fa2ToGen()` 一个函数里；菱形判定对 x↔y 对称，所以不影响选区尺寸公式。
